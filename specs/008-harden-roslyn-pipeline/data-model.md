# Data Model: Roslyn Hardening and SARIF

## LoggingAnalysisContext additions

| Field | Type | Purpose |
|-------|------|---------|
| `CancellationToken` | `CancellationToken` | End-to-end cancellation for analyzer and Roslyn operations |
| `InvocationIndex` | `InvocationAnalysisIndex` | Shared immutable invocation operations for the current syntax tree |
| `Metrics` | internal metrics interface | Optional per-extraction counters and timings |

The context remains scoped to one syntax tree and analyzer execution. Existing semantic model, compilation, workspace, and solution fields remain authoritative.

## GeneratedCodeClassification

Internal value returned by the generated-code detector.

| Field | Type | Rules |
|-------|------|-------|
| `IsGenerated` | `bool` | True only with positive generated-code evidence |
| `Reason` | enum | `None`, `SourceGeneratedDocument`, `AutoGeneratedHeader` |

File suffix is diagnostic context only and never a reason by itself.

## InvocationAnalysisIndex

Immutable per-syntax-tree collection.

| Field | Type | Rules |
|-------|------|-------|
| `Invocations` | ordered immutable collection | Source-order `IInvocationOperation` entries |
| `SyntaxTree` | `SyntaxTree` | Must equal the context tree |
| `CandidateCount` | `int` | Number of syntax candidates considered |
| `BindCount` | `int` | Number of semantic bind requests |

Construction observes cancellation. Consumers do not mutate or rebind entries.

## ExtractionMetrics

Internal, optional, per extraction.

| Counter | Meaning |
|---------|---------|
| `SyntaxTreesVisited` | Trees entering extraction |
| `SyntaxTreesSkippedGenerated` | Trees excluded by policy |
| `InvocationCandidates` | Invocation syntax candidates |
| `OperationBindRequests` | Calls to semantic operation binding |
| `InvocationOperations` | Successful invocation operations |
| `RootRequests` | Syntax-root retrievals |
| `SemanticModelRequests` | Semantic-model retrievals |
| `CompilationRequests` | Compilation retrievals |
| `SymbolFinderSearches` | Cross-solution caller searches |
| `CallerLocations` | Locations returned by caller searches |
| `CacheHits` / `CacheMisses` | Aggregate and named cache metrics |

Timings use monotonic elapsed durations and are not serialized into user reports.

## LoggerUsageRule

Central rule definition.

| Field | Type | Example |
|-------|------|---------|
| `Id` | string constant | `LUT001` |
| `Name` | string constant | `ParameterTypeMismatch` |
| `ShortDescription` | string | Concise SARIF rule text |
| `FullDescription` | string | Remediation-oriented explanation |
| `DefaultLevel` | enum/string | `warning` or `note` |
| `HelpUri` | optional URI | Stable project documentation anchor |

Rule IDs and names are compatibility contracts after release.

## LoggerUsageFinding

Internal immutable source occurrence.

| Field | Type | Validation |
|-------|------|------------|
| `Rule` | `LoggerUsageRule` | Required centralized definition |
| `Message` | string | Deterministic and actionable |
| `FilePath` | string | Required; normalized only at report boundary |
| `StartLine` | positive int | One-based |
| `EndLine` | positive int | Greater than or equal to start |
| `MessageTemplate` | nullable string | Used in fingerprint; empty is normalized |
| `ParameterName` | string | Exact extracted spelling |
| `ParameterType` | nullable string | Empty marker when unknown |
| `Conflicts` | ordered name/type pairs | Ordinal deterministic order |
| `Fingerprint` | lowercase SHA-256 string | Versioned input contract |

Identity/deduplication key:

```text
Rule.Id + normalized path + StartLine + EndLine + ParameterName + ParameterType
```

Fingerprint stability key excludes line numbers and uses the normalized relative path.

## ReportGenerationContext

Additive reporting metadata.

| Field | Type | Purpose |
|-------|------|---------|
| `SourceRoot` | nullable string | Base for repository-relative SARIF artifact URIs |

Future fields require additive evolution. Existing report generation delegates with an empty context.

## SARIF document subset

```text
SarifLog
└── Runs[1]
    ├── Tool.Driver
    │   └── Rules[LUT001, LUT002]
    ├── OriginalUriBaseIds[%SRCROOT%] (when source root available)
    └── Results[]
        ├── RuleId
        ├── Level
        ├── Message.Text
        ├── Locations[1].PhysicalLocation
        └── PartialFingerprints["loggerUsage/v1"]
```

All arrays have deterministic order. No timestamp is emitted.
